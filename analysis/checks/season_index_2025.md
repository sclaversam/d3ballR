## How d3football numbers weeks

- **Week pages:** the composite scoreboard has one page per week, `https://www.d3football.com/scoreboard/{season}/composite?view=N`, with N = 1, 2, 3, ... in calendar order. `view=1` is the week of the first Saturday in September (Sep 6, 2025; also Sep 7 in both 2019 and 2024). A view also holds that week's Thursday / Friday games, and sometimes a Sunday game (2024 view 1 has a Sunday, Sep 8, game).
- **No round labels:** postseason weeks continue the same numbering. There are no round or bowl labels anywhere: NCAA playoff games and bowl games (e.g. the Centennial-MAC Bowl Series) sit together in one Date / Away / Home / Status / Links table. A row with an empty date is a neutral-site note ("@ Canton, Ohio") for the game above it.
- **End of the season:** pages past the last week come back empty (2025: view 17), so `build_season_index()` stops after two empty views. Only some seasons' pages link all their week views (2025 does; 2024 and 2019 link only view 1), so the indexer steps through views rather than reading the links.
- **Our week numbers:** postseason is decided by date, not by d3's label (there is none): `season_type = "postseason"` when `game_date > regular_season_end` from `data-raw/season_dates.csv`. Regular-season `week` = view number. Postseason weeks restart at 1 (cfbfastR): `week = view - first postseason view + 1`.

## 20251122_xsab (Misericordia at Carnegie Mellon, 2025-11-22)

- **How d3 labels it:** it doesn't. On the week 12 scoreboard it is an ordinary row ("Nov. 22 | Misericordia 17 | Carnegie Mellon 24 | Final"), next to the NCAA first-round games, with no round, bowl or "Centennial-MAC Bowl Series" text. The CMU team page lists it as "11/22 vs. Misericordia W, 24-17". The boxscore header reads "Misericordia at Carnegie Mellon - Pittsburgh, Pa. 11/22/2025 - 12:00 PM". In the play-by-play page, the words "Bowl" / "Playoff" appear only in the site navigation menu (checked 2026-10-02). So `season_type` can't tell a bowl from an NCAA playoff game; both are "postseason".
