# stats.ncaa.org pages saved by hand

stats.ncaa.org blocks scripts, so the play-by-play pages for games
ncaa.com can't give us are saved from a browser (Cmd+S, "Webpage, HTML
only") as `{game_id}.html`, where `game_id` is our ncaa.com contest id.
Which games: `data-raw/ncaa/stats_ncaa_candidates.csv`, rows with
`pull_from_stats_ncaa` TRUE.
